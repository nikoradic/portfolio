# Nikola Radic — Developer Portfolio

A personal developer portfolio built with React and TypeScript to present my experience, education, technical skills and contact information.

## Tech stack

- React
- TypeScript
- Vite
- CSS
- Git

## Features

- Responsive portfolio layout
- About / hero section
- Professional experience
- Education
- Skills
- Contact and professional links
- Downloadable CV

## Run locally

```bash
npm install
npm run dev
```
